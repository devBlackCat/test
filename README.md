# Nintendo × Pokémon Kansai Trip Dashboard v15

2027년 5월 간사이 여행 일정 편집기입니다. `index.html`을 Chrome/Edge에서 열면 됩니다.

## 동선 진단 (2026-10-14)

- 날짜별 상단의 **동선 분석** 버튼에서 현재 순서와 개선 후보 순서를 비교할 수 있습니다.
- `assets/route-analysis.js`와 `assets/route-analysis.css`는 기존 일정 편집기 위에 추가된 독립 기능입니다. 기존 공유 일정 JSON 형식, API, Google Sheets 데이터 구조는 변경하지 않습니다.
- 현재 수치는 저장된 주요 시설의 **대략적인 위도·경도 사이 직선거리 합계**입니다. 실제 도보 km, 철도 시간, 환승 횟수 또는 교통비가 아닙니다. 위치 미확정 카드와 국제선 구간은 해당 거리 계산에서 제외됩니다.
- 개선 후보는 직선거리 감소를 기준으로 합니다. 예약·영업시간·역 접근·철도편을 반영한 보장된 최적 경로가 아닙니다. 각 구간의 **Google 지도에서 실제 대중교통 확인** 링크로 검토하세요.
- 입력된 시작/종료 시간, 숙소, 교통 일정, 위치가 없는 커스텀 일정은 순서 변경 대상에서 제외됩니다. 동선 묶음은 한 카드로 유지하고 선택된 장소의 순서를 고려합니다.
- 사용자가 **개선 후보 순서 적용**을 선택하기 전에는 일정 데이터가 변경되지 않습니다. 적용 직후 분석창의 **직전 적용 되돌리기**로 복구할 수 있습니다. 적용 이후에는 기존 공유 자동 저장 흐름을 따릅니다.
- 이후 실제 철도·도보 정확도를 높이려면 각 장소의 좌표 확인, 경로 서비스와 출발시각별 시간표 데이터가 필요합니다.

## v15 공유 저장 (현재 main)

- 현재 저장소는 Google Apps Script + Google Sheets를 공통 데이터 저장소로 사용합니다.
- `assets/config.js`의 `TRIP_API_URL`은 공개 가능한 읽기/쓰기 웹 앱 URL입니다. 비밀번호나 계정 토큰은 아닙니다.
- 사이트 실행 시 공유 일정을 조회하고, `공유 저장` 시 POST 후 JSONP 조회로 실제 반영 여부를 확인합니다.
- 인증 없는 공개 쓰기 API입니다. 여행 일정에 개인정보·예약번호·연락처를 기록하지 마세요.
- 저장 충돌이나 확인 실패 시 JSON 백업 후 재조회하세요.
- 현재 main의 `worker/`와 `data/schedule.json`은 사용하지 않는 과거 Cloudflare/GitHub 방식의 파일입니다.
- 실제 동작 확인은 GitHub Pages에서 저장 → Google Sheets B2 확인 → 다른 브라우저 새로고침으로 진행하세요.

## v14 이전 파일 백업 방식

v14부터 일정/예약 체크 상태를 브라우저 `localStorage`에 저장하지 않습니다.

- **JSON 저장**: 현재 A/B 일정안, 시간, 동선 묶음, 예약 체크 상태를 하나의 JSON 파일로 저장합니다.
- **JSON 열기**: 이전에 저장한 JSON 파일을 선택해 그대로 복원합니다.
- Chrome/Edge에서 File System Access API를 사용할 수 있으면 **JSON 열기**로 연 파일 또는 처음 **JSON 저장**으로 지정한 파일에 계속 덮어쓸 수 있습니다.
- 해당 기능을 사용할 수 없는 실행 환경에서는 `nintendo-kansai-trip-2027.json` 파일을 다운로드하는 방식으로 저장합니다.
- `Ctrl+S` / `Cmd+S`도 JSON 저장으로 연결됩니다.
- 수정 후 JSON 저장을 하지 않은 상태에서 페이지를 닫으려 하면 브라우저가 이탈 경고를 표시합니다.
- 새로고침/브라우저 재실행 후에는 **JSON 열기**로 일정 파일을 다시 불러오면 됩니다.

> v14 코드에는 일정 저장 용도의 `localStorage` 사용이 없습니다.

## 기존 기능

- A · 12일 밤 출발 / B · 13일 출발 독립 일정안
- 장소 / 권역·동선 보기
- 교토·우지·우메다·신사이바시/난바·닛폰바시/오타로드·USJ·신오사카·KIX 등 생활권 중심 분류
- 개별 장소 및 동선 묶음 드래그 추가
- 같은 날짜 내 순서 변경 / 다른 날짜로 이동
- 날짜별 `＋ 일정` 커스텀 일정
- 장소별 예약·티켓 조건 인라인 표시와 완료 체크
- 일정 카드 사이 권역 이동 힌트 및 시간 충돌 경고
- 추천 일정: 12일 밤 KIX 도착 + First Cabin KIX / Hotel Nikko KIX 선택
