# 간사이 Nintendo × Pokémon 여행 일정 대시보드

2027년 5월 12~16일(12일 밤 출발안 / 13일 출발안)을 비교하는 GitHub Pages 기반 일정 편집기입니다.

**사이트:** https://devblackcat.github.io/test/

## 사용 방법

1. 왼쪽 **여행 장소** 목록에서 이름·지역·태그로 검색하거나 `미배정 / 전체 / 배정됨`을 선택합니다. 더 이상 `장소 / 권역·동선` 탭을 나누지 않습니다.
2. 원하는 장소의 `＋` 또는 드래그로 날짜에 배치합니다. 이미 배정된 장소는 미배정 목록에서 숨겨지고, `전체`에서 배정 날짜를 확인할 수 있습니다.
3. 같은 지역을 한꺼번에 넣고 싶다면 지역 제목 아래 **묶음 추가**를 사용합니다. 2곳 이상 선택 가능한 실제 묶음에만 보입니다. 단독 장소 4곳은 묶음으로 중복 노출하지 않습니다.
4. 일정 카드의 **×**는 해당 항목만 삭제하고, 다른 일정에서 쓰지 않는 장소는 목록으로 복귀합니다. 삭제 직후 뜨는 **되돌리기** 버튼으로 복구할 수 있습니다. 동선 묶음 해제는 삭제가 아니라 개별 일정 전환입니다.
5. 직접 추가한 일정은 카드의 **✎**로 제목·메모와 날짜를 수정할 수 있습니다. 시간은 카드에서 조정합니다.
6. 예약 완료는 **일정안 + 날짜 + 장소**별로 체크합니다. 목록·상세 화면에는 예약 조건을 안내하고 완료 여부는 해당 날짜 일정 카드에서만 입력합니다.
7. 자동 저장이 실행되며, 상단 **공유 저장**은 수동 재시도 용도로 사용할 수 있습니다. **백업·복구** 메뉴에서 JSON 백업을 내려받거나 기존 JSON을 불러올 수 있습니다. JSON을 불러온 후에는 공유본 덮어쓰기를 자동 실행하지 않습니다.

## 동선 안내

- 이동 구간에 대략적인 **좌표 기반 직선거리(km)**, 먼 이동 경고, Google 지도 대중교통 길찾기를 표시합니다.
- 직선거리는 철도·도보 실제 주행거리 또는 소요시간이 **아닙니다**.
- 방문 순서 개선 여지가 있는 구간에만 비교 버튼이 나타납니다. 입력된 예약/방문 시간, 예약 필수 장소, 숙박·교통 일정 등은 순서 변경에서 고정합니다.
- 동선 최적화는 캐시와 제한된 탐색을 사용하는 **개선 후보**이지 실제 시간표 기준 최단 경로를 보장하지 않습니다.

## 2026-10-14 5단계 품질 개선

1. **데이터·오류 수정:** 같은 날짜 드래그 인덱스, 초기 조회 실패 뒤 저장 복구, 기존 공유본이 있을 때 빈 일정 덮어쓰기 방지, 옛 교토 동선의 Marufukuro 누락 방지, 불량 JSON 입력 방어.
2. **중복 정리:** 별도 권역·동선 탭, 사용하지 않는 추천 일정/초기화 코드, 옛 탭 CSS 제거. 이미 저장된 동선 묶음 데이터는 유지.
3. **편집 UX:** 통합 검색/배정 필터, 커스텀 일정 수정, 삭제 취소, JSON 백업/가져오기, 카드 투표 버튼은 상세정보로 이동.
4. **성능:** 8개 장소 40,320가지 전수 탐색 대신 빠른 개선 후보 비교, 날짜별 동선 분석 결과 캐시, 필요하지 않은 목록 전체 갱신 방지.
5. **목록 통합:** 개별 장소와 여러 곳을 묶는 편의 기능을 **여행 장소** 한 화면으로 통합. 단일 장소 묶음의 중복 버튼은 숨김.

### 과거 저장 데이터 호환성

- `route-kyoto`처럼 오래된 동선 식별자는 새 묶음으로 변환하되, 새로운 묶음에 포함되지 않는 옛 장소는 **개별 일정으로 보존**합니다.
- 예전 `reservationDone[placeId]` 예약 완료 기록은 JSON 안에 남겨 두되 날짜/일정안이 불명확하여 새 화면에서 자동으로 완료로 간주하지 않습니다. **해당 일정에서 예약 여부를 한 번씩 다시 확인**하세요.
- 기존 일정의 반복 방문이나 이미 배정된 장소는 자동으로 삭제하지 않습니다. `전체` 필터에서 확인하고 필요하면 재배치할 수 있습니다.

## 공유 데이터와 보안

- 현재 공유 저장은 **Google Apps Script + Google Sheets**를 이용합니다. `assets/config.js`에 공개 읽기/쓰기 엔드포인트가 있습니다.
- **서버 측 사용자 인증이 없는 공개 쓰기 API**입니다. 예약번호, 연락처 등 민감한 정보를 일정/메모에 넣지 마세요. 공동 편집에서 데이터 충돌 방지의 완전성은 서버의 실제 GAS 코드 확인이 필요합니다.
- 수정 도중 충돌·네트워크 오류가 발생하면 **백업·복구 → 현재 일정 JSON 백업**을 먼저 이용하세요.
- 첫 접속 공유 일정을 불러오는 동안에는 편집이 잠깐 잠깁니다.
- `worker/`, `data/schedule.json`은 과거 공유 방식의 기록이며 현재 실시간 공유 데이터가 아닙니다.
- 백엔드 설치 안내: [SHARED_SYNC_SETUP.md](SHARED_SYNC_SETUP.md).

## 파일 구성

- `index.html`: 앱 마크업
- `assets/app.js`: 장소 목록·일정 편집·공유 저장·백업/복구
- `assets/style.css`: 전체 UI
- `assets/route-analysis.js`, `assets/route-analysis.css`: 카드 사이 직선거리와 순서 개선 후보
- `assets/config.js`: Google Apps Script 엔드포인트
