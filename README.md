**사이트:** https://devblackcat.github.io/test/

## 사용 방법

1. 최초 접속 시 `data/recommended-itinerary.json`의 **12일 밤 출발 단일 추천 일정**을 미리 보여주고, Google Sheets 최신 공유본을 확인합니다. 처음 전환할 때 **공유 저장**을 눌러 확정하세요. `AI 추천 일정 적용` 버튼은 정적인 권역별 추천 JSON을 다시 적용하며, 호출할 때마다 새로 생성하는 실시간 AI가 아닙니다. 왼쪽 장소 검색과 필터는 계속 쓸 수 있습니다.
2. 원하는 장소의 `＋` 또는 드래그로 날짜에 배치합니다. 이미 배정된 장소는 미배정 목록에서 숨겨지고, `전체`에서 배정 날짜를 확인할 수 있습니다.
3. 같은 지역을 한꺼번에 넣고 싶다면 지역 제목 아래 **묶음 추가**를 사용합니다. 2곳 이상 선택 가능한 실제 묶음에만 보입니다. 단독 장소 4곳은 묶음으로 중복 노출하지 않습니다.
4. 일정 카드의 **×**는 해당 항목만 삭제하고, 다른 일정에서 쓰지 않는 장소는 목록으로 복귀합니다. 삭제 직후 뜨는 **되돌리기** 버튼으로 복구할 수 있습니다. 동선 묶음 해제는 삭제가 아니라 개별 일정 전환입니다.
5. 직접 추가한 일정은 카드의 **✎**로 제목·메모와 날짜를 수정할 수 있습니다. 시간은 카드에서 조정합니다.
6. 예약 완료는 **일정안 + 날짜 + 장소**별로 체크합니다. 목록·상세 화면에는 예약 조건을 안내하고 완료 여부는 해당 날짜 일정 카드에서만 입력합니다.
7. **추천안을 처음 적용했거나 AI 추천 버튼을 누른 직후에는 자동 저장하지 않습니다.** 상단 **공유 저장**을 명시적으로 눌러 Google Sheets에 반영합니다. 한 번 공유 저장이 성공한 뒤부터 일반 일정 편집은 기존 자동 저장으로 동작합니다. **백업·복구**에서 JSON 백업/가져오기도 가능합니다.

## 2026-10-16 프로필 드래그 배정 + 상단 총경비 + 하단 축소 (v21)

- **상단 사진이 실제 배정 수단:** 프로필을 일정 카드에 드래그하여 참가자를 지정합니다. 모바일·키보드 환경에서는 상단 사진을 누른 뒤 원하는 카드를 누릅니다. 상단 사진 선택은 기존 '개인 일정 필터'가 아닙니다.
- **기본 공통 일정:** 기존 카드의 참가자 정보를 지정하지 않은 경우 5명 전원 참여이며 카드에 해당 프로필이 바로 표시됩니다. 원하는 프로필을 클릭하거나 카드 바깥의 페이지 아무 곳에 끌어놓으면 해당 친구만 제외됩니다.
- **직접 배정:** 참가자 설정이 없는 카드에 상단 사진을 처음 놓으면 **그 친구 1명만** 참가자가 됩니다. 이후 다른 사진을 끌어놓으면 추가됩니다. 카드 안의 사진을 클릭하거나 카드 밖 페이지 어디에 놓아도 제외됩니다. 같은 카드에 놓거나 드래그를 취소하면 제외되지 않습니다. 별도 초기화 버튼은 없습니다.
- **상단 총 예상금액:** 전체 5인 합계 + 비용 미확정 건수를 상단에 표시합니다. 누르면 세부 금액, 교통비, 개인별·날짜별 비용 및 선택한 일정의 예상 비용 수정 메뉴를 엽니다. 장소별 비용 입력 및 교통 구간 수정 데이터는 계속 Google Sheets에 저장됩니다.
- **하단의 단일 역할:** 날짜·일정 수·미확인 예약 수·동선 요약, 선택 일정 시간 수정, 예약 확인 및 상세 링크만 남깁니다. 메모 UI, 하단 참가자 선택기, 하단 경비 표는 삭제합니다. 기존 저장된 메모 텍스트는 유실시키지 않으며 추천 일정 정보나 비용 분석에서 여전히 사용할 수 있습니다.
- **기본 비용 가정의 한계:** '예상 합계'는 확인된 가격과 임시 가정의 합계일 뿐, 2027년의 확정 여행비가 아닙니다. 미확정 항목을 별도로 표시하며 확정되지 않은 항공·호텔·교통 구간을 자동으로 0원 취급하지 않습니다.
- **주의:** 사용자가 이미 다른 곳에서 수정한 공유 데이터가 있으면 백업 JSON으로 보관한 후 변경하고, 저장 실패나 충돌 시 편집 내용을 덮어쓰지 않도록 합니다.

## 2026-10-16 5인 공통 일정 · 프로필 · 예상 경비

- **공통 일정은 단 하나:** 기존 `state.plans.use12`의 5/12~5/16 일정만 유지합니다. 친구별 일정 복제/복사 기능은 없습니다.
- **실제 프로필 이미지 5개:** 사용자가 제공한 단체 채팅방 스크린샷의 표시 이름과 각 행의 프로필 이미지를 대응시켜 `assets/participants.js`에 삽입했습니다. 전병훈·양범직·정영석·CM·DoS(남) 순서이며, GitHub Pages의 공개 소스에도 이 이미지와 이름이 들어갑니다.
- **상단 참가자 (v20 변경):** 사진을 카드로 드래그하거나 사진을 선택한 다음 카드를 눌러 참가자로 넣습니다. 더 이상 개인별 화면 흐림 필터가 아닙니다.
- **일정 카드 (v21 변경):** 프로필 사진은 펼침 없이 바로 표시하고, 참가자 삭제는 카드에서 사진 클릭 또는 카드 바깥 드래그로 처리합니다. 나눠 이동하는 경우 공통 일정에 같은 시간대 카드를 여러 개 배치해 참여자를 지정합니다.
- **예상 비용:** `assets/budget.js`에 공식 입장/열차 운임을 출처와 함께 기록하고, 2027년 아직 확정되지 않은 USJ 요금·식비는 **임시 예산 가정**으로 표시합니다. 비용 미확정 장소는 합계에서 제외하고 별도 건수를 노출합니다.
- **교통비:** 기존 직선거리 옆 `＋ 교통비`를 선택하거나 하단의 `이전 일정에서 이곳까지 교통비 설정`을 사용합니다. 도보·철도·버스·택시·기타 및 1인당/차량 전체 금액과 참가자를 지정할 수 있습니다. **직선거리에서 자동으로 운임을 유추하지 않습니다.** 여행 구간의 실 운임을 조사해 입력해야 합니다.
- **예상 경비 화면 (v20 변경):** 상단에 5명 총 예상액·미확정 수를 표시합니다. 클릭하면 날짜별·5명 합계 및 개인별 총액, 교통비와 선택한 카드 예상요금 편집을 모달에 표시합니다. 미확정 요금이 있다면 총액은 완성된 여행 예산이 아닙니다.
- **상단 단순화:** `AI 추천일정`·`저장`·참가자 프로필·총 예상경비를 표시합니다. 날짜 문구·정상 동기화 상태는 숨기고 JSON 백업·가져오기는 **장소 대시보드의 데이터 관리**로 옮겼습니다. 오류/미저장 상태는 계속 알립니다.
- **데이터 호환:** 기존 저장 API, GAS URL과 JSON `version:15`는 그대로 두되 `attendance`, `budgetOverrides`, `transportOverrides` 옵션 객체를 추가합니다. 이전 공유 JSON을 읽으면 모두 기본 5인 참석으로 처리합니다. 실제 GAS에서 추가 필드를 그대로 저장하는지 왕복 검증해야 합니다.
- **AI 추천:** 현재 버튼은 정적 추천 JSON을 적용하는 기존 기능입니다. 적용하면 현재 공통 일정·참가 설정·예상비용 직접 수정이 초기화될 수 있으므로, 먼저 JSON 백업한 뒤 사용하세요.
- **제한:** 참가자별 개별 예약 완료 체크, 경로별 자동 운임 API, 택시 차량 수 자동 추정, 실제 지출/정산은 아직 구현 대상이 아닙니다.

## 2026-10-16 일정 대시보드 UI 개편 (v18)

- **장소 대시보드:** 기존 장소 검색, 이미지, 필터, 추가, 상세 모달을 유지합니다.
- **일정 대시보드:** 각 카드에 작은 장소 썸네일(이미지 미제공 시 종류별 아이콘), 제목, 시간, 예약 상태만 간결하게 표시합니다. 메모가 있을 때만 작은 표시를 남기고 반복되는 `시작/종료` 라벨·상세 설명·접이식 예약 안내는 제거했습니다.
- **하단 일정 편집:** 카드를 선택하면 시간 입력, 메모 작성, 해당 일정의 예약 체크, 장소 상세 접근을 한곳에서 사용합니다. 묶음 내 개별 장소 정보와 묶음 해제 기능도 하단에서 제공합니다. 선택하지 않을 때에는 하루 전체 예약 체크리스트가 나타납니다.
- **거리 안내:** 카드 사이 직선거리·지도 이동 링크는 유지하고 표시 스타일을 부드럽게 정리했습니다.
- **표준/간결 모드:** 카드 썸네일 크기와 보조 문구 밀도를 조절합니다. 모바일에서는 날짜별 보기/편집 모드를 그대로 유지합니다.
- **공유 데이터 보존:** JSON 버전, 상태 스키마, Google Sheets URL, Apps Script 저장·조회 로직은 변경하지 않았습니다. 캐시 갱신을 위해 프론트 에셋에 `?v=18`만 붙였습니다.
- **후속 검토 예정:** 공유 저장 도중 추가 편집 발생 시 자동 재시도와 최종 저장 확인의 경쟁 상태를 별도 패치에서 보강합니다. 현재 공개 공동 편집 방식은 의도된 정책으로 유지합니다.

## 2026-10-15 화면·모바일 사용성 개선

- **카드 디자인:** 일자 카드의 진한 왼쪽 색 라인을 없애고 제목·시간·한 줄 메모 중심으로 정리했습니다. 티켓·숙소·입장 확인은 작은 라벨로 표시하고, 상세 예약 문구는 카드에서 펼칠 수 있습니다.
- **거리 안내:** 위치를 확인할 수 없는 커스텀/이동 카드 또는 같은 시설권역의 사실상 0km 거리에는 반복 경고 박스를 표시하지 않습니다. 확인된 구간만 직선거리·지도 링크를 보여줍니다. 직선거리는 실제 도보/철도 거리와 다릅니다.
- **하단 패널:** 날짜별 일정 수, 예약 체크 필요 건수, 확인 가능한 구간의 직선거리 합계, 선택한 장소 정보·메모 입력, 예약 체크리스트, 동선 비교를 한곳에서 제공합니다.
- **화면 밀도:** `간결하게 보기` 버튼으로 카드 정보를 압축하고 다시 `여유 있게 보기`로 전환할 수 있습니다. 밀도 설정만 이 브라우저에 저장되며, 여행 일정 JSON은 건드리지 않습니다.
- **모바일/태블릿:** 날짜 탭으로 한 번에 하루만 표시합니다. 기본은 읽기 모드이며 `편집하기`에서 시간 수정·삭제·직접 일정 추가가 가능합니다. `장소 추가`로 목록을 열어 검색·일정 배치를 할 수 있습니다. PC에서는 드래그 편집을 유지합니다.
- **공유 안전:** 기존 Google Sheets 저장·백업/복구와 추천 JSON 파일을 유지했습니다. 모바일/밀도/선택 상태는 공유 데이터에 추가하지 않습니다.

- 이동 구간에 대략적인 **좌표 기반 직선거리(km)**, 먼 이동 경고, Google 지도 대중교통 길찾기를 표시합니다.
- 직선거리는 철도·도보 실제 주행거리 또는 소요시간이 **아닙니다**.
- 방문 순서 개선 여지가 있는 구간에만 비교 버튼이 나타납니다. 입력된 예약/방문 시간, 예약 필수 장소, 숙박·교통 일정 등은 순서 변경에서 고정합니다.
- 동선 최적화는 캐시와 제한된 탐색을 사용하는 **개선 후보**이지 실제 시간표 기준 최단 경로를 보장하지 않습니다.

## 2026-10-14 5단계 품질 개선

1. **데이터·오류 수정:** 같은 날짜 드래그 인덱스, 초기 조회 실패 뒤 저장 복구, 기존 공유본이 있을 때 빈 일정 덮어쓰기 방지, 옛 교토 동선의 Marufukuro 누락 방지, 불량 JSON 입력 방어.
2. **중복 정리:** 별도 권역·동선 탭, 사용하지 않는 추천 일정/초기화 코드, 옛 탭 CSS 제거. 이미 저장된 동선 묶음 데이터는 유지.
3. **편집 UX:** 통합 검색/배정 필터, 커스텀 일정 수정, 삭제 취소, JSON 백업/가져오기, 카드 투표 버튼은 상세정보로 이동.
4. **성능:** 8개 장소 40,320가지 전수 탐색 대신 빠른 개선 후보 비교, 날짜별 동선 분석 결과 캐시, 필요하지 않은 목록 전체 갱신 방지.
5. **목록 통합:** 개별 장소와 여러 곳을 묶는 편의 기능을 **여행 장소** 한 화면으로 통합. 단일 장소 묶음의 중복 버튼은 숨김.

### 과거 저장 데이터 호환성

- `route-kyoto`처럼 오래된 동선 식별자는 새 묶음으로 변환하되, 새로운 묶음에 포함되지 않는 옛 장소는 **개별 일정으로 보존**합니다.
- 예전 A/B JSON을 가져와도 화면은 `use12` 하나로 통합됩니다. A안에 항목이 없고 B안만 있으면 B안의 13~16일 일정을 단일 12일안에 이관합니다. 옛 예약 체크는 날짜/대상 확인 후 사용하세요.
- 기존 일정의 반복 방문이나 이미 배정된 장소는 자동으로 삭제하지 않습니다. `전체` 필터에서 확인하고 필요하면 재배치할 수 있습니다.

## 공유 데이터와 보안

- 현재 공유 저장은 **Google Apps Script + Google Sheets**를 이용합니다. `assets/config.js`에 공개 읽기/쓰기 엔드포인트가 있습니다.
- **서버 측 사용자 인증이 없는 공개 쓰기 API**입니다. 예약번호, 연락처 등 민감한 정보를 일정/메모에 넣지 마세요. 공동 편집에서 데이터 충돌 방지의 완전성은 서버의 실제 GAS 코드 확인이 필요합니다.
- 수정 도중 충돌·네트워크 오류가 발생하면 **백업·복구 → 현재 일정 JSON 백업**을 먼저 이용하세요.
- 첫 접속 공유 일정을 불러오는 동안에는 편집이 잠깐 잠깁니다.
- `worker/`, `data/schedule.json`은 과거 공유 방식의 기록이며 현재 실시간 공유 데이터가 아닙니다.
- 백엔드 설치 안내: [SHARED_SYNC_SETUP.md](SHARED_SYNC_SETUP.md).
